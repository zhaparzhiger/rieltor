# Деплой на Render (бесплатный тариф)

Приложение упаковано в Docker и собирается из этого репозитория. Готово к
Render, но так же поедет на Koyeb, Fly.io или любой другой контейнерный хостинг.

## Что нужно знать про бесплатный тариф

- **Сервис засыпает** после 15 минут без запросов, первый заход после сна
  занимает около минуты.
- **Диск эфемерный.** Кэш страниц, геокэш и последний результат живут только до
  перезапуска. Приложение это переживает: не нашёл кэш — сходит заново.
- **512 МБ памяти.** Хватает, но не запускайте два прогона одновременно.
- **IP дата-центра.** Krisha и OLX относятся к таким адресам строже, чем к
  домашнему интернету: возможны более частые «сайт не ответил» и отказы отдавать
  телефоны. Это ограничение площадки, а не приложения — локально работает лучше.
- **Прогон длится 5–7 минут.** Он идёт фоновой задачей на сервере, вкладку можно
  закрыть. Но если Render перезапустит контейнер посреди прогона, задача пропадёт
  и её надо будет запустить заново.

## Шаги

1. **Render → New → Blueprint**, выбрать репозиторий `zhaparzhiger/rieltor`.
   Render прочитает `render.yaml` и предложит создать сервис `rieltor`.
2. Заполнить переменные, которые Render спросит (они не лежат в git):

   | Переменная | Значение |
   | --- | --- |
   | `GOOGLE_CLOUD_PROJECT` | `gen-lang-client-0537370402` |
   | `GOOGLE_SERVICE_ACCOUNT_JSON` | всё содержимое `google-key.json` одной строкой |
   | `GEMINI_API_KEY` | оставить пустым, если используется Vertex |
   | `KRISHA_COOKIE` | необязательно, см. ниже |

   `GEMINI_USE_VERTEX=1`, `GOOGLE_CLOUD_LOCATION=global` и
   `GEMINI_MODEL=gemini-2.5-flash` уже прописаны в `render.yaml`.

3. **Create** — Render соберёт образ (5–7 минут) и поднимет сервис.
   Проверить: `https://<имя>.onrender.com/api/health` должен ответить
   `{"ok":true,"ai":true,...}`. Если `ai:false` — не подхватился ключ.

### Проще, чем Vertex

Если возиться с сервисным аккаунтом не хочется, возьмите ключ в Google AI Studio
и задайте `GEMINI_API_KEY=<ключ>`, а `GEMINI_USE_VERTEX=0`. Остальные переменные
Google тогда не нужны.

### Телефоны Krisha

Krisha отдаёт номер только вошедшим в аккаунт. Чтобы номера подтягивались
автоматически, скопируйте свою строку `Cookie` из DevTools (Network → любой
запрос к krisha.kz) в переменную `KRISHA_COOKIE`. Это ваша сессия — храните её
как пароль и не коммитьте. Без неё приложение показывает превью «+7 701 …», а
номер можно вписать в карточку руками, кнопка WhatsApp соберётся сразу.

## Локальная проверка образа

```bash
docker build -t rieltor .
```

```bash
docker run --rm -p 3007:3007 --env-file .env.local rieltor
```

## Что проверить после деплоя

1. `/api/health` — сервис жив.
2. `/api/ai-ping` — Gemini отвечает (при исчерпанной квоте вернёт `quota: true`).
3. Открыть главную, нажать «Начать парсинг» и посмотреть лог: если Krisha
   отвечает «страница не открылась», площадку режут по IP — попробуйте позже или
   снимите галочки Krisha и работайте по OLX.
