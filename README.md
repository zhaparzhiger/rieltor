# Жильё у TAU — Астана

Приложение ищет однокомнатное жильё рядом с Turan Astana University: парсит
krisha.kz и olx.kz, считает расстояние до университета, выбрасывает подселение
и посуточную аренду, а остальное ранжирует через Gemini.

## Запуск

```bash
npm install
npm run dev
```

Откроется на <http://localhost:3007>. Настройки слева, кнопка «Начать парсинг»
запускает прогон, лог идёт в реальном времени.

## Что настраивается

| Параметр | По умолчанию |
| --- | --- |
| Цена | 60 000 – 85 000 ₸ / мес |
| Радиус | 3 км от Дукенулы 29 (координаты TAU: 51.181568, 71.43244) |
| Комнат | не больше 1 (студия считается за одну) |
| Источники | krisha квартиры/комнаты, olx квартиры/комнаты |

## Как это работает

1. **Выдача.** Krisha отдаёт HTML — карточки читаются через cheerio.
   OLX кладёт всё состояние страницы в `window.__PRERENDERED_STATE__`
   (публичный REST-эндпоинт закрыт CloudFront, HTML — нет).
2. **Фильтры без сети.** Цена, число комнат, посуточная аренда, подселение —
   всё по ключевым словам из `lib/normalize.ts`.
3. **Координаты.** У OLX точки на карте нет (только центроид района), у Krisha
   она есть, но лежит на странице объявления. Поэтому адрес сначала ищется в
   OpenStreetMap по тексту, и только короткий список догружается с Krisha.
   Точность помечается: попадание в дом (`geocoded`) или только в улицу (`approx`,
   к радиусу добавляется 1.5 км допуска).
4. **ИИ.** Gemini получает объявления пачками по 12 и ставит оценку 0–100
   с вердиктом, плюсами, минусами и оценкой риска подселения и обмана.
   Это самый долгий шаг: примерно минута на пачку.

5. **Телефон и сообщение.** По финальному списку подтягиваются номера, а Gemini
   в том же запросе пишет готовый текст первого сообщения хозяину. В карточке —
   кнопка «WhatsApp», текст можно поправить перед отправкой.

Прогон запускается как фоновая задача на сервере (`lib/jobs.ts`), а страница
раз в секунду спрашивает прогресс у `/api/progress`. Поэтому вкладку можно
закрыть или перезагрузить — задача доработает, а страница подхватит её обратно.
Результат в любом случае пишется в `data/state.json`.

> В режиме `next dev` правка любого файла проекта перезапускает модули и
> убивает идущий прогон — во время парсинга код лучше не трогать.

## Ограничения источников

- **Krisha блокирует IP на уровне TCP** за всплеск запросов. Поэтому между
  обращениями стоит пауза 900 мс, страницы выдачи кэшируются на 20 минут,
  карточки объявлений — на неделю (`data/cache/`), а при четырёх подряд отказах
  парсер останавливается и работает с тем, что успел собрать. Если увидели
  «Krisha перестала отвечать» — подождите 10–30 минут.
- **OLX** отдаёт всё стабильно, но адрес пишут в свободной форме, поэтому у части
  объявлений расстояние остаётся неизвестным. Такие карточки остаются в выдаче,
  если район правобережный, и помечаются «адрес неточный».
- **Телефоны.** OLX отдаёт номер той же ручкой, что и кнопка «Показать номер» на
  сайте, но полсотни запросов подряд ловят «обнаружена подозрительная активность»
  и выдача глохнет. Поэтому сразу подтягиваются номера только 12 лучших вариантов
  (с паузой 2 секунды), остальные — по кнопке «Показать номер» в карточке, по
  одному запросу в момент, когда номер реально нужен.
  Krisha показывает номер только вошедшим в аккаунт: в карточке видно превью
  «+7 701 …». Хотите автоматически — вставьте свою строку Cookie в
  `KRISHA_COOKIE` (это ваша сессия и ваш риск, по умолчанию выключено).
  В любом случае номер можно вписать в карточку руками — кнопка WhatsApp
  соберётся сразу.
- **Nominatim** просит не больше одного запроса в секунду — очередь строго
  последовательная, ответы кэшируются в `data/geocache-v2.json`.

## Конфигурация

`.env.local`:

```
GEMINI_USE_VERTEX=1
GOOGLE_CLOUD_PROJECT=...
GOOGLE_CLOUD_LOCATION=us-central1
GOOGLE_APPLICATION_CREDENTIALS=...\google-key.json
GEMINI_MODEL=gemini-2.5-flash
```

Либо просто `GEMINI_API_KEY=` от Google AI Studio. Без ключа приложение работает,
но без оценок — только фильтры и расстояния.

## Структура

```
app/api/parse     запуск фоновой задачи парсинга
app/api/progress  прогресс и результат текущей задачи
app/api/state     последний сохранённый прогон
app/api/ai-ping   диагностика Gemini (?full=1 — тот же вызов, что и скоринг)
lib/jobs.ts       фоновая задача: логи, стадии, результат
lib/sources       парсеры krisha.kz и olx.kz
lib/pipeline.ts   оркестрация: выдача → фильтры → координаты → ИИ
lib/geo.ts        haversine и геокодер с кэшем
lib/normalize.ts  эвристики подселения, посуточной аренды, разбор заголовков
data/             результаты, кэш страниц и геокодера (в .gitignore)
```
